# Decision Options Register

Before committing to a direction for fuzzy or high-impact work, generate 2-4 options.

## Option Fields

For each option, record:

- option
- cost
- risk
- reversibility
- time to feedback
- alignment with the stated goal and inferred goal
- maintenance burden
- expected learning
- failure mode

## Common Options

- minimal patch
- prototype or experiment
- documentation/specification first
- architecture refactor
- use an existing tool or library
- defer or do nothing

Prefer options that learn quickly and keep low-confidence choices reversible. Reject options that add broad architecture or dependency cost without clear evidence.
